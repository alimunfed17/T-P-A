## Features
- Build an itinerary with chatbot with user Inputs 
- Show pre-generated trips with Gemini API
- Responsive design suitable for desktop and mobile devices.

---

## Tech Stack

- **Next.js**: Frontend for bettering routing and strucuture.
- **React**: Frontend for building UI.
- **Radix-UI**: For Building functional logic to UI Components.
- **Tailwind CSS**: Styling and responsive design.
- **TypeScript**: Type safety and better code quality.

## Setup & Installation

#### 1. Install dependencies:
```bash
cd frontend

npm install
# or 
yarn install
```

#### 2. Set up environment variables:

Create a `.env` file in the frontend root directory:
```bash
BASE_URL=http://localhost:8000
```
This points to your backend API.

---

## Running the Application
Start the development server:
```bash
npm run dev
# or
yarn dev
```

The frontend should now be running at:
```bash
    http://localhost:3000
```


Ensure your backend server is running simultaneously to allow API communication.

## Usage

**1. Home Page**: Quick links to plan your itineraries and show suggested trips

**2. Planner Page**:

- Input your responses based on your travel preferences 
- Generates a day to day or activity to activity itinerary based on the responses

**3. Trips Page**:

- Displays a list of trips being pre-generated by Gemini API
- Shows the detailed trip in the modal.
